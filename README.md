# Meerkat

The Meerat library enables general combinator-style parsing in Scala. 

More information about Meerkat can be found: http://meerkat-parser.github.io/

## Fork information

This repository is a fork of https://github.com/niktrop/Meerkat which itself is a fork of the original
https://github.com/meerkat-parser/Meerkat project.

This repository contains simple, surface-level changes to refresh the project for 2026 such that it can be used
as a highlighting test for the [Scala Plugin for IntelliJ IDEA](https://github.com/JetBrains/intellij-scala).
